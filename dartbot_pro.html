Zet DartBot Pro op je Telefoon

Volledig scherm • Eigen App-Icoon • Offline klaar

Directe installatie beschikbaar! Installeer DartBot Pro met één tik op je toestel.
1 Open via een vaste web-link (HTTPS)

Download dit bestand (dartbot_pro.html) en sleep het gratis naar app.netlify.com/drop (of GitHub Pages / Vercel). Je krijgt direct een eigen https://... link die je op je telefoon opent.

🍎 iPhone / iPad (Safari)
  1. Open de link in Safari.
  2. Tik onderin op het Deel-icoon (vierkant met pijltje omhoog).
  3. Scroll omlaag en tik op "Zet op beginscherm".
  4. Tik rechtsboven op "Voeg toe".
🤖 Android (Chrome)
  1. Open de link in Google Chrome.
  2. Tik rechtsboven op de 3 puntjes (⋮).
  3. Kies "App installeren" of "Toevoegen aan startscherm".
  4. Bevestig met "Installeren".
